# Система движения

Движение объясняет интерфейс (откуда пришла карточка, что отфильтровалось), а не украшает. Бюджет: ничего не должно ухудшать LCP/INP/CLS. Целевое CLS = 0.

## Инструменты и роли
- **Переходы между страницами**: Astro View Transitions (`<ClientRouter />` в общем layout). Общие элементы связываем через `transition:name` (карточка оффера в списке и на странице обзора, заголовок), остальное идёт стандартным crossfade. Для интерактивных островков `transition:persist`.
- **Анимации на странице**: GSAP, подключается лениво (`import('gsap')` по первому событию или `IntersectionObserver`), не в критическом бандле. Код лежит в `web/packages/motion`, компоненты вызывают его функции.
- **Фильтры и сортировка витрины**: GSAP Flip (`Flip.getState` до изменения DOM, `Flip.from` после). Карточки не перерисовываются, а перемещаются.
- **Маскот-карта** (тёплое приветствие, первый визит): показывается один раз; флаг `localStorage` читать и писать только внутри `try/catch` (приватный режим и блокировки бросают исключения); без флага при ошибке не показывать вовсе, а не показывать каждый раз.

## Жёсткие правила
1. Анимируем только `transform` и `opacity` (иногда `clip-path`). Никаких `width/height/top/left/margin` в анимации.
2. Под анимированный элемент резервируем место (размеры или `aspect-ratio`), нулевой сдвиг соседей.
3. `prefers-reduced-motion: reduce`: переходы страниц сводим к мгновенной смене или короткому fade, GSAP-анимации не запускаем (`gsap.matchMedia()` или проверка `matchMedia`), маскот без движения.
4. Длительности: микро 120–200 мс, переходы 250–400 мс, easing один на сайт (токены в motion-пакете). Не больше одной «яркой» сцены на экран.
5. Бюджет JS: motion-код сайта до 30 КБ gzip суммарно без GSAP; GSAP и плагины грузить по необходимости (Flip только на страницах с фильтром). Не подключать ScrollTrigger «на всё».
6. Нет анимации на каждом блоке при скролле (reveal-on-scroll допустим для 1–2 секций на странице).
7. `will-change` ставить на время анимации и снимать; не оставлять на статике.
8. Скрипты идемпотентны при повторном заходе (`astro:page-load`), слушатели и таймлайны снимаются на `astro:before-swap`.
9. Без JS страница полностью читаема и кликабельна (прогрессивное улучшение).

## Как проверять через Playwright MCP
1. Поднять `rencredit-dev` (порт 4321) или `npm --prefix web run build` + preview.
2. `browser_navigate`, затем `browser_take_screenshot` до, во время (после `browser_wait_for` 100–200 мс) и после перехода. Размеры 1440x900 и 375x812 (`browser_resize`).
3. Замер CLS через `browser_evaluate`:
```js
await new Promise((resolve) => {
  let cls = 0;
  new PerformanceObserver((list) => {
    for (const e of list.getEntries()) if (!e.hadRecentInput) cls += e.value;
  }).observe({ type: 'layout-shift', buffered: true });
  setTimeout(() => resolve(cls), 3000);
});
```
Должно быть 0 (допуск 0.01). Повторить после действия (клик по фильтру, переход на другую страницу).
4. Эмуляция reduced motion: `browser_emulate_media` с `reducedMotion: reduce`, убедиться, что движения нет и контент доступен.
5. Горизонтальный скролл: `document.documentElement.scrollWidth <= window.innerWidth`.
6. `browser_console_messages`: ошибок и предупреждений нет.
7. Маскот: проверить первый визит (очистить `localStorage` через `browser_evaluate`), повторный визит (не показывается), и режим с бросающим `localStorage`.
