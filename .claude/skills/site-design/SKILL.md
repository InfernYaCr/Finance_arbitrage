# Дизайн витрин: уникально, быстро, продаёт оффер

Каждый сайт сети это отдельная витрина офферов с собственным лицом. Донора и соседние сайты сети не копируем: футпринт (одинаковые токены, шрифты, сетка) сам по себе паттерн для поисковиков.

## Токены
- Все цвета, шрифты, радиусы, тени, отступы живут в `src/styles/global.css` в блоке `@theme` (Tailwind 4) как CSS-переменные. В компонентах только токены, никаких «магических» hex.
- Токены сайта уникальны: другая основная гамма, другая пара шрифтов, другой радиус, чем у донора и других витрин сети. Нового сайта = новый набор токенов, а не копия `global.css`.
- Шрифты: самохостинг (woff2 в `public/fonts`, `font-display: swap`, preload одного основного начертания). Google Fonts по CDN не подключаем.
- Не вводить новые цвета и шрифты в обход `@theme`.

## Структура страницы
- Витрина офферов это главный экран. На главной и на посадочных гайдах (`guides`) карточки офферов видны без прокрутки на 375 px. Текст SEO идёт ниже витрины.
- Карточка оффера показывает то, что решает клик: сумма, срок, ставка в день, ПСК/переплата, решение за N минут, возраст. Данные берутся из `content/offers/*.json`, не вводятся руками в разметке.
- CTA всегда ведёт на `/go/<poolId>/` и имеет `rel="sponsored nofollow"` (при `target="_blank"` добавлять `noopener`). Прямые ссылки `my.saleads.pro` в разметку не вставляем.
- Рядом с витриной: дисклеймер «Информация не является публичной офертой. Сайт не является банком и не выдаёт займы», условия оффера обновляются по данным кабинета.
- Футер: реквизиты владельца, ссылки на политику, раздел «Как мы зарабатываем» (партнёрская модель), нейтральное название сайта.

## Запрещено (кластеры «ИИ-шаблона»)
1. Фиолетово-синие градиенты, неон на тёмном, стеклянные «glass» панели везде.
2. Hero «заголовок по центру + два CTA + три иконки в карточках» как единственная композиция.
3. Сетка одинаковых карточек с одинаковой мягкой тенью как единственный приём. Карточка оффера отличается от карточки статьи.
4. Служебная «обвязка»: ТРЕКИНГ-КАПС-метки над каждым заголовком, точка-разделитель, тире-подписи.
5. Нумерация, где нет последовательности.
6. Fade-and-slide на каждом блоке (анимации: см. скилл `motion-system`).
7. В заголовке одно выделенное слово цветом в каждом блоке. Допустимо один раз в hero.
8. Стоковые «улыбающиеся люди с ноутбуком». Нет подходящего изображения, используем типографику, цифры, иллюстрацию в стиле сайта.
9. Копирование цветов, логотипа, фирменных блоков и вёрстки донора.

## Обязательно в каждой правке
- Мобильный вид 375 px без горизонтального скролла: `document.documentElement.scrollWidth <= window.innerWidth` (проверяет агент `page-reviewer`).
- Контраст текста WCAG AA (4.5:1 обычный, 3:1 крупный). Бренд-цвет на белом проверять по числу, не на глаз.
- `:focus-visible` с заметным контуром у всех интерактивных элементов; фильтры и табы управляются с клавиатуры.
- Цели нажатия не меньше 44x44 px на мобильном.
- Картинки: `width`/`height` или `aspect-ratio`, `loading="lazy"` кроме LCP, `alt` осмысленный (у декоративных `alt=""`).
- Семантика: один `h1`, иерархия заголовков без пропусков, `nav`/`main`/`footer`, хлебные крошки на вложенных страницах.
- Не копировать донорские картинки и их URL. Логотипы МФО/банков берутся только из материалов самого оффера (кабинет Saleads) и хранятся локально.
- Анимации: только по скиллу `motion-system`, учитывать `prefers-reduced-motion`.

## Проверка после правки
```bash
node scripts/check.mjs --quick
npm --prefix web run build
```
Затем агент `page-reviewer`: скриншоты 1440 и 375, горизонтальный скролл, консоль, CLS.
