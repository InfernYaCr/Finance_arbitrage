- [ ] `meta description` is present where source data has it.
- [ ] One primary H1 exists per content page where appropriate.
- [ ] Canonical URLs are correct.
- [x] `sitemap.xml` is generated from buildable pages.
- [x] `robots.txt` is generated and references sitemap.
- [ ] Internal links are valid or intentionally redirected.
- [ ] Image URLs render or are intentionally proxied/copied.
- [ ] Old source-domain media mode is intentionally selected: placeholder, source, or local.
- [x] Old extracted contact details are replaced by `siteConfig`/env values.

- [ ] No generated pages use excluded external redirect content.

- [ ] Representative JSON-LD output is validated before launch.

## Template Architecture

- [ ] Content JSON is not edited for design-only changes.
- [ ] Page type mapping is centralized by path/section.
- [ ] Layouts exist for home, article, archive, service, portfolio, contact, FAQ, and generic pages.
- [ ] SEO/meta/schema helpers are shared across layouts.
- [ ] Theme/design tokens are centralized.
- [ ] A redesign can be done by changing layouts/components/theme files without re-parsing content.

## Affiliate / Partner Links

- [ ] Partner links are managed from central config/data, not hardcoded in templates.
- [ ] Promo/sponsor slots are managed from central config/data.
- [ ] Links/promos can be targeted by page type, section, path, or exact page ID.
- [ ] Partner links can be disabled or replaced quickly.
- [ ] UTM parameters are generated centrally.
- [ ] Paid/sponsored/affiliate outbound links use `rel="sponsored nofollow"` by default.
- [ ] Outbound monetization links are auditable before launch.
- [ ] Sponsor copy is visible to users and not hidden/cloaked.
- [ ] Analytics does not leak sensitive form data through affiliate URLs.

- [ ] Analytics scripts are injected once per page.

## Forms / Anti-Spam

- [x] Feedback/contact form locations are defined.
- [x] Form delivery method is chosen: Beget `mail.php` generated into `dist/`.
- [x] Form secrets are not committed.

- [ ] Captcha/turnstile is added only if needed.
- [ ] Form success and error states are tested on live Beget host.
- [ ] Submitted data does not expose sensitive information in logs.
