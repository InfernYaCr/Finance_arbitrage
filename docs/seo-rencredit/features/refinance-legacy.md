**OSS.** Готовых живых библиотек по рефинансированию нет. На GitHub лежат учебные калькуляторы «снежный ком / лавина» без лицензий и звёзд. `duaneking/unburyme` (MIT, 42★, последний пуш в 2020) подходит только как референс UX. `@formulajs/formulajs` 4.6.1 (живая, 2026-07) умеет PMT/IRR, но для 15 строк формул зависимость не нужна. **Вывод: формулы пишем сами в `src/lib/finance.ts` и проверяем assert-тестом.**

Формулы (ядро для всех инструментов):

```
r = ставка_годовых / 12 / 100
Аннуитет:   A = S · r / (1 − (1 + r)^−n)
Переплата:  A·n − S
Старое:     Σ по кредитам A_i · n_i (остаток платежей)
Новое:      S_new = Σ остатков + удерживаемые из тела комиссия/страховка;  итого = A_new·n_new + разовые расходы (оценка, госпошлина, справки)
Выгода = Старое − Новое;  окупаемость = min k: Σ_{1..k}(Σ A_i − A_new) ≥ разовые расходы
Флаг «ловушка срока»: A_new < Σ A_i, но итого_new > Старое → «платёж меньше, переплата больше на X ₽»
ПСК (ч. 2 ст. 6 353-ФЗ, базовый период — месяц, ЧБП = 12):
    найти i: Σ_k ДП_k / (1 + i)^k = 0, где ДП_0 = −(сумма, реально полученная на погашение), ДП_k = платёж + обязательная страховка;
    ПСК = 12 · i · 100   (бисекция 0…1, 60 итераций)
ПДН = Σ среднемесячных платежей / среднемесячный доход · 100
    (кредитка: платёж считается от лимита по методике 6579-У — процент сверить по тексту Указания;
     нет подтверждения дохода → банк может взять оценку по 7286-У; без согласия на запрос КИ → ПДН = 100%)
Досрочка: «уменьшить срок» n' = −ln(1 − S'·r/A) / ln(1 + r);  «уменьшить платёж» A' = аннуитет(S', n_ост)
Лавина: лишние деньги идут на долг с max ставкой;  снежный ком: на долг с min остатком;  симуляция по месяцам
```

## 3. Идеи

### R1. «Выгодно ли рефинансировать?» — калькулятор консолидации с вердиктом и точкой окупаемости. impact high / effort M
**Механика.** 1–5 строк «кредит / кредитка / займ МФО»: остаток, ставка, осталось месяцев, платёж (можно не заполнять, тогда считается). Затем новое предложение: ставка, срок, комиссия, страховка («включить в тело / отдельно / нет»), разовые расходы. На выходе:
- старый и новый платёж;
- итоговая переплата по каждому варианту;
- **выгода в ₽**;
- **месяц окупаемости**;
- **ПСК нового кредита рядом со среднерыночной ЦБ** (29,339% для >100 тыс.) и предельной (39,119%);
- флаг «ловушка срока»;
- вердикт светофором.

Пресеты: «2 кредитки + кредит», «займы МФО → банк», «один кредит под меньшую ставку». Параметры хранятся в URL (ссылкой можно поделиться) и в localStorage («ваш прошлый расчёт»).

**Мост к офферу.** Под результатом показываем OfferCard Т-Банка и Альфы, если сумма попадает в диапазон оффера. Если вердикт «невыгодно», блок называется «Сравнить предложения», а сверху подсказка «вероятно, выгоднее досрочное погашение» со ссылкой на R4.

**Отличие от конкурентов.** Несколько долгов, страховка, ПСК, окупаемость.

**Где.** `/refinansirovanie/kalkulyator/` и встраивание в 14 статей категории.

### R2. Хаб `/refinansirovanie/` с маршрутизатором сценариев. impact high / effort S
Сейчас категории с 14 статьями и самым сильным наследием домена некуда вести: CTA уходит на `/kredity/`. На хабе:
- мини-версия R1 (сумма, ставка, новая ставка → «экономия ≈ X ₽»);
- `CompareTable` только с офферами рефинансирования;
- маршрутизатор «Ваша ситуация»: снизить платёж / объединить кредитки / закрыть МФО / плохая КИ / ипотека / ИП / отказали;
- блок «Ставка ЦБ сегодня» (R8);
- список статей категории;
- FAQ + `FAQPage`.

CTA категории в `cta.ts` переключить на хаб. Хаб же служит целевой страницей для старых URL `/credit/refinansirovanie-kredita.html`, `…drygih-bankov…` (решает SEO-аудит).

### R3. ПДН-калькулятор «Одобрят ли рефинансирование» + ветка «Антиспираль». impact high / effort M
Адаптация `debt-pdn-antispiral` из finhelp с поправками на 2026 год и рефинансирование. Ввод: доход (подтверждён / нет), список платежей, лимиты кредиток. На выходе:
- ПДН сейчас и **ПДН после рефинансирования** (нужно сверить по 6579-У, исключаются ли платежи по погашаемым кредитам);
- расшифровка через МПЛ IV кв. 2026: при ПДН >50% банк может выдать таким заёмщикам не больше 15% объёма, при >80% — 1%. Человек видит, почему ему отказывают, без «гарантий».

Ветвление:
- ≤50% → R1 и офферы рефинансирования;
- 50–80% → «как снизить ПДН» (закрыть кредитку, снизить лимит, подтвердить доход), реструктуризация;
- >80% или просрочки → R7: каникулы, реструктуризация, МФЦ-банкротство, ББанкрот.

Займы МФО в этой ветке не показываются вообще (требование ymyl-content: не поощрять спираль).

### R4. План погашения: лавина / снежный ком / досрочка + календарь `.ics`. impact medium / effort M
Тот же список долгов из R1/R3 (одна модель, один `finance.ts`). Ползунок «могу добавлять ₽/мес». На выходе:
- дата выхода из долгов и переплата по стратегиям «минимальные платежи», «лавина», «снежный ком» (SVG-график);
- сравнение досрочки «уменьшить срок» и «уменьшить платёж»;
- сравнение «рефинансировать vs гасить досрочно».

Кнопка «Добавить платежи в календарь»: `.ics` по RFC 5545 собирается Blob-ом примерно в 30 строк, напоминание за 3 дня, в описании события ссылка на расчёт. Это даёт возвраты на сайт без регистрации.

### R5. «Почему отказали в рефинансировании» — диагностика без персональных данных. impact medium / effort S
Закрывает старый кластер «отказы» (7 URL в Wayback). 8 вопросов: просрочки за 12 мес., реструктуризация в истории, число кредитов, ПДН (ссылка на R3), стаж, подтверждение дохода, кредит выдан меньше 3–6 мес. назад, тип долга (МФО / кредитка / залог). Правила в JSON: баллы → причины → план исправления. Что предлагается в плане:
- бесплатная КИ через Госуслуги и БКИ, 2 раза в год;
- оспорить ошибку в БКИ;
- подождать N месяцев;
- подтвердить доход;
- альтернатива из R7.

Только эвристика, без «одобрят»; цель Метрики `refi_diag_<level>`. Движок общий с `approval-chances-no-pd` из finhelp.

### R6. Чек-лист документов + шаблоны заявлений. impact medium / effort S
Закрывает старый кластер «документы» (3 URL). Конструктор: тип долга (потребкредит / кредитка / МФО / авто / ипотека / ИП) и профиль (зарплатный клиент, без справок, пенсионер) → список с галочками в localStorage и печать.

Шаблоны: заявление о досрочном погашении, запрос справки об остатке и реквизитах, уведомление об отказе от страховки в период охлаждения, заявление на реструктуризацию и каникулы. Механика из `document-templates-library` finhelp: форма → предпросмотр через `textContent` → `window.print()`, данные остаются в браузере.

Для ипотеки отдельно: оценка, снятие и наложение обременения, новая страховка. Отсюда мост в R9.

### R7. Навигатор «Рефинансирование, реструктуризация, каникулы или банкротство». impact high / effort S
Дерево решений на 4–6 вопросов с реальными порогами из JSON (каждый порог с источником и датой):
- **каникулы**: доход упал на 30%+, лимиты 450 тыс. / 150 тыс. / 1,6 млн;
- **реструктуризация**: временные трудности, банк вправе отказать;
- **МФЦ-банкротство**: 25 тыс.–1 млн и ИП окончено за отсутствием имущества;
- **судебное банкротство**;
- **рефинансирование**: ПДН до 50%, нет просрочек.

На каждом листе: что это, плюсы и минусы, последствия для КИ, шаблон из R6, оффер, если он уместен. На листе «рефинансирование» — Т-Банк и Альфа. На листе «банкротство» — **сначала бесплатный МФЦ**, потом ББанкрот 18 750 ₽ (нужен `kind: debt_relief` в схеме офферов).

Закрывает старые URL `kogda-vygodno…a-kogda-kreditnye-kanikyly`, `refinansirovanie-ili-restryktyrizaciia`. Тексты берём из готовых статей finhelp: `bankrotstvo-cherez-mfc.json`, `bankrotstvo-fizicheskih-lic-cherez-sud.json`, `posledstviya-bankrotstva.json`, `otkaz-ot-strahovki-po-kreditu`.

### R8. «Ставка рефинансирования ЦБ сегодня» + «рефинансировать сейчас или ждать». impact medium / effort S
Старый кластер домена (`stavka-refinansirovaniia-chto-eto`, `razmer-stavki-…`), и сам запрос «ставка рефинансирования» частотный. При сборке скрипт тянет SOAP `KeyRateXML` в `key_rate.json`. Даты заседаний берём из `cal_mp`, на сегодня это 23.10.2026 и 18.12.2026.

Виджет:
- ставка с датой «на ДД.ММ»;
- график за 12 месяцев;
- таймер до заседания;
- подсказка «если ставка снизится на 1 п.п., ваш расчёт R1 даст ещё X ₽».

`.ics` «пересчитать после заседания» создаёт повод вернуться. Сайт статический, поэтому нужна пересборка по cron в дни заседаний; без неё показываем видимую дату. Готовый дизайн — `dive-key-rate-hub.md` finhelp. Расширение — калькулятор процентов по ст. 395 ГК на той же ставке.

### R9. Рефинансирование ипотеки: калькулятор + экономия на страховке. impact medium / effort M
Самый большой старый кластер: около 27 URL. Ипотечных офферов нет, но есть `strahovanie-ipoteki` (Черехапа, Polis812). При рефинансировании ипотеки полис оформляют заново, и рыночный полис обычно дешевле банковского; это реальная статья экономии.

Калькулятор: остаток, ставка, новая ставка, расходы (оценка, госпошлины, страховка, проценты в переходный период) → выгода и окупаемость (движок R1). Отдельно строка «страховка банка vs рынок». Подсказки про налоговый вычет после рефинансирования и семейную ипотеку (условия сверять). Монетизация — офферы страхования ипотеки; ипотечный рефинанс добавить, если он появится в Saleads.

### R10. Сценарные посадочные с предзаполненным калькулятором. impact high / effort M
6–8 страниц: кредитки, займы МФО, автокредит, с плохой КИ, пенсионерам, без справки о доходах, под залог недвижимости, ИП. На каждой R1 с пресетом сценария (например, для кредиток среднерыночная ПСК ЦБ 54% vs предложение) и честным блоком «когда не выгодно». Для МФО: «банк рефинансирует займы реже; сначала R5».

Это механика восстановления старых кластеров, где есть интерактив и уникальные данные ЦБ, а не тонкий текст. URL и редиректы выбирает SEO-аудит. Тексты пишем заново по `ymyl-content`. Готовые статьи категории (`refinansirovanie-kreditov-s-plohoi-kreditnoi-istoriei…`, `…dlia-ip…`) становятся основой страниц «плохая КИ» и «ИП».

### R11. «Сравнение программ рефинансирования банков» с датой сверки. impact medium / effort M
В пуле всего 2 оффера, но статьи про Сбер, ВТБ, Россельхоз, УБРиР и Открытие уже есть. Таблица `refi-programs.json`: ставка от/до, ПСК, сумма, срок, сколько кредитов можно объединить, нужна ли справка, возраст, дата проверки, ссылка на источник.
- Партнёры: CTA `/go/` + «Реклама» + erid.
- Не партнёры: только информация, без ссылок.

В R1 кнопка «подставить условия банка X». Пересмотр раз в месяц (задача в news-pipeline). Параллельно проверить в каталоге Saleads, какие ещё офферы рефинансирования можно подключить (`connect-missing --dry-run`, это делает владелец токена).

## 4. Общая техника (для всех R)
- Одна модель «список долгов» и один `src/lib/finance.ts` (аннуитет, ПСК-бисекция, ПДН, лавина/снежный ком, досрочка) + один assert-тест формул с эталонными примерами. Эталоны сверить с calcus.ru.
- Компоненты на vanilla `<script>`, как в `offers-ui.ts`, без новых зависимостей. Вывод чисел через `textContent`.
- Справочные пороги (ПСК ЦБ, МПЛ, каникулы, МФЦ, ключевая ставка) хранить в `src/data/refi-thresholds.json` с полями `value / source / asOf`. На странице видна дата «данные ЦБ на …».
- Цели Метрики: `refi_calc_input`, `refi_calc_result` (параметры `verdict`, `amount_bucket`), `refi_offer_click`, `pdn_result_<zone>`, `nav_leaf_<leaf>`, `ics_download`, `doc_print`. Сейчас целей нет, без них приоритеты дальше не проверить.
- Офферный блок с «Реклама», юрлицом, erid и диапазоном ПСК, ссылки только `/go/<poolId>/` с `rel="sponsored nofollow"`.
- `kind: debt_relief` в схеме офферов + карточка ББанкрот. Нужно для R3 и R7.
- Не использовать бренд «Ренессанс Кредит» и не размещать его офферы (правило ymyl-content). Домен созвучен, поэтому в UI инструментов везде бренд «Мерка».

## 5. Порядок
1. `finance.ts` + тест → R1 + R2 (хаб) + цели Метрики. Это даёт монетизацию Т-Банка и Альфы сразу.
2. R3 + R7 + `debt_relief`: самая дорогая выплата (18 750 ₽) и сильный YMYL-сигнал.
3. R8 (дёшево, свежесть данных), R5, R6.
4. R4, R10, R9, R11 по данным целей.

## Риски
- YMYL: ошибка в формуле вредит человеку. Нужны тест, дисклеймер «расчёт ориентировочный» и видимые даты данных.
- Пороги каникул и МФЦ взяты из вторичных источников, перед публикацией сверить с consultant.ru / pravo.gov.ru. Процент для кредиток в ПДН и исключение рефинансируемых платежей сверить с текстом 6579-У.
- Статика: ставка ЦБ и среднерыночная ПСК устаревают. Нужен cron-ребилд (ПСК ЦБ публикует раз в квартал, ставку меняет 8 раз в год).
- Нельзя писать «одобрят» и «спишем долги» (38-ФЗ). Уязвимой аудитории не показывать займы МФО.
