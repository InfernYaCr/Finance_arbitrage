# rencredit («Мерка»): автоматизация новостей и живых данных

Линза: news-data-automation. Дата проверки: **2026-10-19**. Каждый фид и API ниже я проверил `curl` в этот день: HTTP-код, размер, число `<item>`, дата первого материала. Отчёт опирается на `docs/seo/features/news-rss.md` и `live-data.md` (сделаны для finhelp-ru) и на `finhelp_ideas.json`. Всё из них перепроверено и адаптировано под стек rencredit: Astro 7, коллекции `content.config.ts`, статика на Beget. Технический SEO здесь не повторяю, он разбирается в `docs/seo-rencredit/0*.md`.

## TL;DR

1. **Раздел новостей стоит.** На живом сайте 3 новости, последняя от 01.10.2026. Четвёртая лежит в `draft`. Скилл `news-pipeline` требует 2–5 новостей в неделю, а конвейера, который бы это обеспечивал, нет: нет `rss.xml`, нет сбора фидов, нет расписания. Старый `/feed/` от WordPress отдаёт 301 на главную.
2. **Цифры ЦБ в контенте прописаны руками и скоро устареют.** В `service-pages/vklady.mdx` (текст и FAQ) и `debetovye-karty.mdx` написано «На 13 октября 2026 года ключевая ставка — 14%». Заседание ЦБ **23.10.2026** через 4 дня, после него эти строки могут стать неправдой. Предел ПСК `pskMax: z.number().max(292)` зашит в схему, а ЦБ меняет его раз в квартал (следующая публикация ожидается около 13.11.2026).
3. **Минимальное решение:** один stdlib-скрипт `scripts/fetch_facts.py`, который пишет `src/data/facts.json` (ставка, дата следующего заседания, лимиты ПСК, реестр МФО, чёрный список). Astro читает этот файл при сборке. Поверх него:
   - хаб `/klyuchevaya-stavka/`;
   - сборочная проверка «оффер есть в реестре ЦБ» (сегодня все 22 МФО-оффера в реестре);
   - инструмент «Проверить МФО»;
   - ежемесячная заметка «Что изменится с 1-го числа».
4. **Новости из официальных фидов через «входящие», а не автопостинг.** Расписание кладёт кандидатов в inbox. Существующий агент `news-writer` пишет черновик с `draft: true`, `ymyl-fact-checker` его проверяет, `draft` снимает человек. Цель: 2–3 новости в неделю из ЦБ, Минфина, правительства и Консультанта.
5. **Ближайшие инфоповоды:**
   - заседание ЦБ 23.10.2026 в 13:30 МСК;
   - Минфин 12.10: предложение усилить защиту граждан от нелегальных кредиторов;
   - ЦБ 09.10: семейная ипотека на срок свыше 15 лет;
   - ЦБ 13.10: мониторинг максимальных ставок по вкладам;
   - «Что изменится с 1 ноября 2026».

## 3. Архитектура: минимум, который работает

```
scripts/fetch_facts.py   (stdlib: urllib, xml.etree, zipfile; ~150 строк)
  ├─ KeyRateXML (SOAP)           → keyRate {value, since, history[]}
  ├─ press/keypr + dkp/cal_mp    → nextMeeting {date, time:"13:30"}
  ├─ psk *_mfo.xlsx / *_ko.xlsx  → pskCaps {category: {avg, cap, quarter}}
  ├─ list_MFO.xlsx               → mfoRegistry {regNo: {name, type, date}}  (+ excluded)
  └─ BlackList.xml               → blacklist shards (public/data/bl/*.json)
          ↓  пишет атомарно (tmp → rename); при ошибке оставляет прошлое значение
web/apps/rencredit/src/data/facts.json   (коммитится — у каждого числа есть история в git)
          ↓
Astro: import facts → <Fact k="keyRate"/>, токены {{keyRate}} в frontmatter FAQ, zod-refine pskMax ≤ facts.pskCaps,
       гейт «cbrLicense ∈ mfoRegistry» в getOffers()

scripts/news_inbox.py    (stdlib; ~80 строк)
  fetch 7 фидов → dedup (sha1 link, seen.jsonl) → keyword-фильтр → inbox.json (title, link, date, feed, hint)
          ↓
news-writer (агент) → src/content/news/YYYY-MM-DD-slug.md, draft:true → ymyl-fact-checker → человек снимает draft
          ↓
build → deploy-beget.sh → indexnow.mjs (только изменённые URL)
```

Почему так:
- `facts.json` лежит в git, поэтому каждое изменение цифры проходит через diff. Это и есть ревью для YMYL.
- Дашборды строятся при сборке (ставка меняется 8 раз в год, ПСК раз в квартал), клиентский JS для цифр не нужен: Яндекс видит их в HTML.
- PHP-патчер на Beget (уровень C из `live-data.md`) нужен только для ежедневных курсов, а курсы для «Мерки» вне фокуса. **Пропускаем.** Вернуться к нему, если появится страница с ежедневными данными.

Где запускать: **локально или на Beget, не в GitHub Actions.**
- Гео-доступность cbr.ru и gosuslugi с зарубежных раннеров я не проверял; запросы шли с текущей машины.
- `news-writer` нужен Claude-сеанс. Проще всего запускать через scheduled task Claude Code или локальный `launchd`/`cron`.
- Workflow `deploy-rencredit.yml` оставить для сборки и выкладки, но данные он должен брать из закоммиченного `facts.json`.

## 5. Идеи (по приоритету)

### 5.1 `facts.json` + `<Fact>`: убрать зашитые цифры ЦБ (S, high)
- **Проблема.** «На 13 октября 2026 года ключевая ставка — 14%» стоит в `vklady.mdx` (текст и FAQ) и `debetovye-karty.mdx`. 23.10 ставка может измениться. Лимит необлагаемого дохода 160 000 ₽ (1 млн × 16% на 01.01.2026) тоже считается из истории ставки.
- **Решение.** `fetch_facts.py` пишет `src/data/facts.json`, который состоит из `keyRate`, `keyRateSince`, `nextMeeting`, `taxFreeDepositIncome2026` и `pskCaps`. Компонент `<Fact k="keyRate" />` выводит «14% (с 27.07.2026, по данным Банка России)». В FAQ из frontmatter (там MDX не работает) токены `{{keyRate}}` подставляются в `lib/content.ts`.
- **Что даёт.** Честный `updatedDate`, меняется только при реальном изменении факта. Нет устаревших YMYL-утверждений.

### 5.2 Гейт «оффер в реестре ЦБ» + бейдж на карточке (S, high)
- **При сборке.** Каждый `kind: mfo` оффер проверяется: его `cbrLicense` должен быть в `facts.mfoRegistry`. Если оффер найден в «Исключённых» или не найден вовсе, сборка падает (или оффер прячется через уже существующий `removed-offers.json`).
- **На странице.** На `OfferCard` и в обзоре выводится бейдж «В реестре ЦБ № 2110573000002, МФК/МКК, проверено 19.10.2026» со ссылкой на `cbr.ru/finorg/`.
- **Состояние сегодня.** Все 22 оффера проходят проверку.
- **Что даёт.** Комплаенс: не рекламировать исключённые МФО. E-E-A-T. Повод для еженедельной пересборки.

### 5.3 Хаб `/klyuchevaya-stavka/` + протокол дня заседания (M, high)
- **Состав страницы:**
  - текущая ставка из `facts.json`;
  - обратный отсчёт до 23.10, 13:30 (чистый CSS/JS, данные из сборки);
  - история решений с 2013 года и SVG-график, рисуется при сборке, `@pbn/motion` только для анимации появления;
  - блоки «что это значит» для займов (на МФО не влияет: предел 0,8% в день задан законом), кредитов и рефинансирования (переход в `/kredity/`), вкладов (`/vklady/`), карт;
  - FAQ.
- **Основа текста.** Взять `sites/finhelp-ru/editorial/klyuchevaya-stavka-prognoz.json` (19,5 тыс. символов, 7 FAQ, 12 источников ЦБ). В `finhelp_articles_reuse.tsv` его статус `not_reviewed`, поэтому сначала его проверяет `ymyl-fact-checker`, затем переписываем под голос «Мерки». Прогнозы аналитиков показываем только со ссылкой на источник.
- **Протокол заседания** описан в §4. На каждое заседание выходит новость, хаб ссылается на неё, новость ссылается на хаб.
- **Конкуренты отстают по свежести:** ppt.ru (обновлено 16.02.2026) и banki.ru wikibank (27.04.2026), см. `live-data.md`.

### 5.4 Конвейер «официальные фиды → inbox → news-writer» (M, high)
- `news_inbox.py`, ~80 строк stdlib.
- **Двухступенчатый фильтр.** Сегодня в eventrss ключевые слова дали 25 совпадений из 100, но большинство из них шум («денежно-кредитной политики»). Поэтому после keyword-фильтра идёт отбор агентом по вертикали сайта.
- **Кандидаты прямо сейчас:**
  - Минфин 12.10, Чебесков: «предлагает усилить защиту граждан от нелегальных кредиторов»;
  - ЦБ 09.10: «Семейная ипотека на срок свыше 15 лет»;
  - ЦБ 13.10: мониторинг максимальных ставок по вкладам.
- **Привести в порядок попутно:**
  - сделать `source` обязательным в схеме `news` (`z.url()` без `.optional()`);
  - имена файлов вести как `YYYY-MM-DD-slug`;
  - убрать `CtaCallout`/`CtaNext` из шаблона новости, оставить одну нейтральную ссылку на гайд, как требует скилл;
  - в `NewsArticle` добавить `publisher`, `image`, `isBasedOn: source`;
  - в двух живых новостях заменить вторичные источники (Интерфакс, Банки.ру) на первоисточник (pravo.gov.ru).

### 5.5 «Что изменится с 1-го числа» + `/kalendar-izmenenij/` с `.ics` (M, high)
- **Ежемесячная новость.** Первая — «Что изменится с 1 ноября 2026». Даты вступления в силу берём из Консультанта, pravo.gov.ru API, ЦБ и ФНС (1 декабря — срок уплаты имущественных налогов).
- **Постоянная страница-календарь.** Строится при сборке из frontmatter новостей (новое поле `effectiveDate`) и генерирует статический `.ics`.
- **Уже известные даты для календаря:**
  - этапы закона о микрозаймах: 01.10.2026 (ПСК >200% при двух и более займах) и 01.04.2027 (один «дорогой» займ);
  - заседания ЦБ.
- **Что даёт.** Предсказуемый ежемесячный всплеск спроса и повод вернуться на сайт (поведенческие факторы).

### 5.6 «Проверить МФО или сайт займа» `/proverka-mfo/` (M, high)
- **Поиск** по названию, ИНН, рег. номеру и домену. Ищем в реестре (действующие и исключённые) и в чёрном списке ЦБ (`BlackList.xml`, 2,3 МБ, поле `Sign`: «признаки финансовой пирамиды», «нелегальный кредитор»).
- **Без бэкенда.** Реестр — JSON примерно на 100–150 КБ. Чёрный список режем на шарды по первому символу домена или названия и кладём в `public/data/bl/`. Поиск на ванильном JS, `search.json.ts` уже есть как образец.
- **Результат.** «В реестре с … / исключена … / в списке ЦБ с … как …» и ссылка на `cbr.ru/finorg/`. Под ним — «Сравнить легальные МФО» (витрина `/zaimy/`).
- **Попутно.** Еженедельный дайджест «Новые нелегальные кредиторы в списке ЦБ» как новость-таблица. Ссылки с форумов вида «как не нарваться» придут сами.

### 5.7 Предельные ПСК ЦБ: страница + сборочная проверка офферов (S, medium)
- **Страница** `/predelnaya-psk/` строится из `*_mfo.xlsx` и `*_ko.xlsx`. Первая таблица — на IV кв. 2026; около 13.11 добавится таблица на I кв. 2027.
- **Проверка.** Вместо `pskMax: z.number().max(292)` — `refine` по категории оффера (сумма и срок → категория ЦБ).
- **Бейдж.** «ПСК не выше предела ЦБ на IV кв. 2026» на карточках, только для офферов с подтверждённым диапазоном ПСК (`lib/offers.ts` уже требует диапазон для рекламы).

### 5.8 `rss.xml` + `/feed/` + дистрибуция в Дзен и Telegram (S, medium)
- **Фид.** Эндпоинт `src/pages/rss.xml.ts` (RSS 2.0 строкой, без `@astrojs/rss`): новости и статьи, `content:encoded` с полным текстом без промо-блоков, `enclosure` из `cover`.
- **Редиректы.** В `.htaccess:164` заменить `^feed/?$ → /` на `^feed/?$ → /rss.xml`: подписчики и краулеры старого WordPress-фида перестанут теряться.
- **Дзен.** Требования к импорту (`news-rss.md`): ≥10 материалов, ≥3 за месяц. При нынешних 3 новостях Дзен подключать рано, сначала конвейер из 5.4.
- **Telegram.** Автопост заголовка и ссылки при снятии `draft` (Bot API), только после появления канала.

### 5.9 Блоки «Что изменилось» на evergreen-страницах (M, medium)
- **Связка по тегам.** Новость с `tags: [МФО, ПСК]` автоматически попадает в блок «Последние изменения» (1–3 пункта) на `/zaimy/`, в гайдах и статьях `category: zaimy`.
- **Обратные ссылки.** Новость ссылается на 2–3 статьи из 22 имеющихся.
- **Даты.** `dateModified` evergreen-страницы меняется, только если блок действительно изменился.
- **Что даёт.** Перелинковку и глубину просмотра (поведенческие факторы) почти без нового текста.

## 6. Чего не делать

- **Ленту чужих новостей и автопостинг без ревью.** Это авторское право (Интерфакс прямо запрещает перепечатку), «малоценный контент» и YMYL-риск.
- **Курсы валют, `/kurs-valyut/`, PHP-патчер.** Головные запросы забирает колдунщик Яндекса, а «Мерка» сравнивает займы и кредиты, не валюту. Вернуться, если появятся валютные карты или вклады.
- **Страницы «ставка на дату» или «курс на дату».** Это тонкий контент.
- **Сбор данных в GitHub Actions** до проверки гео-доступа cbr.ru с раннеров.
- **Новые npm-зависимости** под RSS и XML: хватает stdlib Python и строкового шаблона в Astro.

## 7. Риски

- **Хрупкий HTML-парсинг.** `press/keypr`, `cal_mp`, ссылки на xlsx ПСК, `avgprocstav` зависят от вёрстки ЦБ. SOAP-методы и `dataservice` стабильнее. Нужен тест: минимум N строк, разумные границы значений, дата не старше X. При сбое оставляем прошлое значение с его датой и шлём алерт.
- **Шум фидов.** Ключевые слова цепляют «денежно-кредитную политику»; нужен второй фильтр агентом. Пустой inbox — нормальный исход: «лучше меньше, но проверенные».
- **Скорость в день заседания.** Пресс-релиз выходит в 13:30. Выкладка с вычиткой до 15:00 реалистична, только если владелец на связи; иначе публиковать вечером, без гонки.
- **Даты «Что изменится».** Законопроект — не закон. В календарь попадают только акты, опубликованные на pravo.gov.ru, с реквизитами.
- **Госуслуги** недоступны автоматически (сертификат НУЦ Минцифры). Темы самозапрета и кредитной истории обновляем вручную.
