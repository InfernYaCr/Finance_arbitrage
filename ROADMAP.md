## Трек B — PBN-инфраструктура

### B1 · Multi-donor pipeline (приоритет #1)

- [ ] **B1.1** Убрать хардкод mosseo.ru из `crawl_pages.py` — сделать донора параметром (`--donor-url`)
- [ ] **B1.2** Интеграция Firecrawl MCP как альтернативный бэкенд краулинга
- [ ] **B1.3** Универсальный экстрактор контента (не зависит от WP REST или конкретных CSS-классов)
- [ ] **B1.4** Тестовый прогон на втором доноре (выбрать нишу)

### B2 · Batch deploy

- [ ] **B2.1** `sites/` структура — каждый сайт = `sites/site-NNN/.env` с брендом/FTP/аналитикой
- [ ] **B2.2** `build-all.sh` — итерируется по `sites/`, собирает и деплоит каждый
- [ ] **B2.3** Dry-run режим — `--dry-run` показывает что будет задеплоено без деплоя

### B3 · Вариативность тем (footprint)

- [ ] **B3.1** Вынести дизайн-токены в `themes/theme-alpha/tokens.css` (текущая тема)
- [ ] **B3.2** Тема Beta — другая цветовая схема, другой шрифт, другие радиусы
- [ ] **B3.3** Тема Gamma — другая структура секций (1-колонка vs 2-колонки)
- [ ] **B3.4** `theme.json` в конфиге сайта — выбор темы при сборке

### B4 · Link config (исходящие ссылки)

- [ ] **B4.1** `links.json` — централизованная таблица: `site_id → money_url → анкор → страницы → rel`
- [ ] **B4.2** PromoSlot читает из `links.json`, не из хардкода
- [ ] **B4.3** CLI-утилита: `update-links.py --money-url X --anchor Y` — обновляет все сайты

### B5 · MCP-воркфлоу (Firecrawl + Exa + Playwright)

- [ ] **B5.1** Exa: запрос → список донор-кандидатов по нише → оценка по объёму/качеству
- [ ] **B5.2** Firecrawl: краулинг выбранного донора → нормализация → JSON
- [ ] **B5.3** Playwright: smoke-test сетки после деплоя → отчёт OK/FAIL по каждому сайту
- [ ] **B5.4** Filesystem: сводка конфигов сетки, массовое обновление ссылок

## Порядок реализации

```
A1.1 → A1.2 → A1.3   (сайт выглядит нормально)
       ↓
A2.1 → A2.2           (конверсионный контент)
       ↓
A3.1 → A3.2 → A3.3   (мобильная версия)
       ↓
B1.1 → B1.2 → B1.3   (multi-donor pipeline)
       ↓
B2.1 → B2.2           (batch deploy)
       ↓
B3.1 → B3.2           (темы)
       ↓
B4.1 → B4.2           (link config)
       ↓
B5.x                  (MCP воркфлоу, требует API ключей)
       ↓
A4.x + B5.x           (полировка параллельно)
```
